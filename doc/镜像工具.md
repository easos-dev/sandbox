# 沙箱里的工具与用法

写给在沙箱里执行命令的 AI，也是镜像内容的唯一清单。镜像里的位置：`/usr/local/share/sandbox/TOOLS.md`，需要时 `cat` 它。
同目录还有 `font-specimen.py`（生成字体样张 PDF）与 `tools-check.sh`（逐项核对工具是否可用）。
改 Dockerfile 时同步改这里：文末的清单由冒烟测试逐项核对，文档列了而镜像没有、或镜像装了而文档没列，冒烟都会失败。

## 运行环境

- **系统**：Debian 13（trixie）。Python 3.13（`python` 就是 `python3`），Node 20，shell 是 bash。
- **账号**：每条命令以当前命名空间的系统账号执行，没有 sudo，不能 `apt install`。家目录 `~` 只有本账号能进；同一命名空间的不同会话共用家目录。
- **工作目录**：当前会话目录 `~/conversations/<会话 ID>/`。运行器把每条命令的完整输出写在其中的 `out/<执行号>.txt`。
- **时间与输出**：单条命令最长 600 秒，超时整组进程被终止；长任务拆成几步。输出超过 16 KiB 时只回传尾部，大量输出先写文件，再用 `head`、`rg` 挑着看。
- **环境变量**：只有 HOME、USER、LOGNAME、SHELL、PATH、`LANG=C.UTF-8`、`TERM=dumb`、`PYTHONUNBUFFERED=1`、`MPLBACKEND=Agg`、NODE_PATH、MATPLOTLIBRC。没有任何密钥或 EasOS 凭证。
- **时区**：UTC。要本地时间就在命令前加 `TZ=Asia/Tokyo` 或 `TZ=Asia/Shanghai`。
- **网络**：能访问公网。私网、链路本地、运营商 NAT、33 段等内部地址一律拒绝（连接立即失败）。本机回环可用，可以起本地服务自己用。
- **装包**：`pip install 包名` 自动装到 `~/.local`，装出的命令在 `~/.local/bin`（已在 PATH 最前）；`npm install 包名` 装在当前目录。都需要公网，装的东西同一命名空间的各会话共用。
- **没有的**：图形界面与显示器、浏览器内核、Java、完整版 TeX Live。替代办法见文末“没有的东西”。

## 生成 PDF：按需求挑

| 需求 | 用什么 | 写法 |
| --- | --- | --- |
| 报告、海报、名片等自由版式 | HTML + CSS → weasyprint | `python3 -c "import weasyprint; weasyprint.HTML('a.html').write_pdf('a.pdf')"`；HTML 必须写 `<meta charset="utf-8">` |
| Word、Excel、PPT 转 PDF | LibreOffice | `soffice --headless --convert-to pdf --outdir out 文件.docx` |
| 公式多、学术排版 | LaTeX | 中文 `\documentclass{ctexart}` 用 `xelatex`；日文 `\documentclass{ltjsarticle}` 用 `lualatex` |
| Markdown 转 PDF | pandoc | `pandoc a.md -o a.pdf --pdf-engine=xelatex -V CJKmainfont="Noto Serif CJK SC"`，或 `--pdf-engine=weasyprint` |
| 程序逐个元素画 | reportlab、fpdf2 | 字体要传文件路径，见“字体 · 程序里写字体”；reportlab 用不了思源字体 |
| 图片拼成 PDF | img2pdf | `img2pdf *.png -o out.pdf` |
| PDF 表单、合并后加页码等 | pypdf、pikepdf、pdf-lib（Node） | |

## PDF：读取与处理

- **抽文字**：`pdftotext -layout a.pdf -`；表格用 `pdfplumber`（`page.extract_tables()`）；版面与图片坐标用 PyMuPDF（`import pymupdf`；旧名 `fitz` 仍能用，但会提示弃用）。
- **合并、拆页、旋转、解密**：`qpdf --empty --pages a.pdf b.pdf -- merged.pdf`、`qpdf a.pdf --pages . 1-3 -- part.pdf`、`qpdf --rotate=+90:1 a.pdf r.pdf`、`qpdf --decrypt --password=xxx in.pdf out.pdf`。
- **转图片**：`pdftoppm -r 150 -png a.pdf page`（每页一张）；也可 `magick -density 150 a.pdf[0] p.png`。
- **取出内嵌图片**：`pdfimages -png a.pdf img`。看字体：`pdffonts a.pdf`。看页数等信息：`pdfinfo a.pdf`。
- **压缩**：`gs -sDEVICE=pdfwrite -dPDFSETTINGS=/ebook -o small.pdf a.pdf`。
- **其他**：`mutool`（MuPDF 命令行）、`pikepdf`（底层改对象）、`pypdf`。

## OCR

- 语言：`chi_sim`（简体）、`chi_tra`（繁体）、`jpn`（日文横排）、`jpn_vert`（日文竖排）、`eng`，是 tesseract 官方的高精度模型。多语言用加号连接：`-l chi_sim+eng`。
- 图片：`tesseract 图.png - -l chi_sim`。默认的版面分析面向整页；只有一行字的小图加 `--psm 7`，一块文字加 `--psm 6`。
- 扫描版 PDF 加文字层（之后能搜索、能复制）：`ocrmypdf -l chi_sim+jpn+eng in.pdf out.pdf`；已有文字层的页面加 `--skip-text`。

## Office 文档

- **转换**：`soffice --headless --convert-to pdf|docx|xlsx|pptx|odt|html|png 文件`。同一账号同时跑多个 soffice 会抢配置目录，只有一个成功；要并行就给每个进程单独的配置目录：
  `soffice -env:UserInstallation=file:///tmp/lo-$$ --headless --convert-to pdf a.docx`。每个账号第一次启动 LibreOffice 要多等几秒。
- **Word**：python-docx（生成与修改）、docxtpl（Word 模板填空）、mammoth（docx 转 HTML）、Node 的 `docx`。中文字体要同时设东亚字体：
  `run.font.name = "宋体"; run._element.rPr.rFonts.set(qn("w:eastAsia"), "宋体")`（`from docx.oxml.ns import qn`）。
- **Excel**：openpyxl（读写、样式、公式）、xlsxwriter（只写，图表丰富）、xlrd（旧版 .xls）、pyxlsb（.xlsb）、`pandas.read_excel` / `to_excel`、Node 的 `exceljs`；命令行 `xlsx2csv`。
- **PPT**：python-pptx、Node 的 `pptxgenjs`（`require("pptxgenjs")` 直接可用）。
- **其他**：pandoc（Markdown、HTML、docx、epub 互转）、odfpy（ODF）、msoffcrypto-tool（解密带密码的 Office 文件）、`uno`（用 Python 驱动 LibreOffice）。
- Windows 文档里写的宋体、微软雅黑、ＭＳ 明朝、Calibri 等字体名，转换时会自动换成镜像里风格对应的字体，见“字体 · 名字映射”。

## 图片与音视频

- **ImageMagick**：`magick in.jpg -resize 50% out.webp`、`magick a.png b.png +append ab.png`。**vips**（大图更快更省内存）：`vips thumbnail in.jpg out.jpg 800`。
- **压缩与格式**：`cwebp -q 80 in.png -o out.webp`、`optipng`、`pngquant`、`jpegoptim`；HEIC 用 Python 的 `pillow_heif`（`pillow_heif.register_heif_opener()` 后 Pillow 就能打开）。
- **SVG**：`rsvg-convert -w 800 a.svg -o a.png`，或 Python 的 `cairosvg`。流程图：`dot -Tpng a.dot -o a.png`（graphviz）。
- **元数据**：`exiftool 图.jpg`。**二维码**：`qrcode` 生成，`pyzbar` 识别。**视觉**：OpenCV（`import cv2`）、scikit-image。Node：`sharp`。
- **音视频**：`ffmpeg`、`ffprobe`，例如 `ffmpeg -i in.mov -vf scale=1280:-2 out.mp4`。

## 数据分析与画图

- **表格数据**：pandas、polars、pyarrow（Parquet）、duckdb（直接对文件写 SQL：`duckdb.sql("select * from 'a.csv'")`）、sqlite3 命令行、csvkit（`in2csv`、`csvsql`、`csvstat`）、jq。
- **统计与建模**：numpy、scipy、statsmodels、scikit-learn、sympy、networkx。中文分词 jieba，词云 wordcloud（要给 `font_path`）。
- **画图**：matplotlib、seaborn 默认就能显示中日文（西文用 DejaVu Sans，汉字假名落到思源黑体）。
  想换字体就改 `font.family` 列表，例如 `plt.rcParams["font.family"] = ["serif", "Noto Serif CJK SC"]`；只写 `"serif"` 会缺中文字。
- **plotly**：只能导出 HTML（`fig.write_html`），没有浏览器内核，导不出 PNG/PDF；静态图用 matplotlib。

## LaTeX

- 引擎：`xelatex`、`lualatex`，以及 `latexmk -xelatex a.tex`。已装常用宏包、推荐字体、理科宏包（amsmath、siunitx、algorithm 等）、TikZ。
- **中文**：`\documentclass{ctexart}`（或 `ctexrep`、`ctexbook`、`\usepackage{ctex}`），用 xelatex。默认宋体是思源宋体、黑体是思源黑体，
  `\heiti`、`\kaishu`（文鼎楷体）、`\fangsong`（朱雀仿宋）可直接用，斜体用楷体。文档自己写 `fontset=...` 时以文档为准。
- **日文**：`\documentclass{ltjsarticle}`，用 lualatex，默认原ノ味明朝与角ゴシック。
- **任意字体**：`\usepackage{fontspec}` 后 `\setmainfont{Playfair Display}`；中文用 xeCJK 的 `\setCJKmainfont{LXGW WenKai}`。
- XeLaTeX 生成的 PDF 里，思源字体显示成 `NotoSerifCJKjp` 之类的名字，这是正常的，字形是简体中文。
- 每个账号第一次用 lualatex 编译中文约 10 秒（处理字体缓存），之后很快。

## 字体

镜像里约 370 个字族。`fc-list : family | sort -u` 列出全部；`python3 /usr/local/share/sandbox/font-specimen.py 样张.pdf` 生成按语言分组的样张。

### 怎么挑

| 用途 | 中文 | 日文 | 英文 |
| --- | --- | --- | --- |
| 正文 | Noto Serif CJK SC（宋）、Noto Sans CJK SC（黑）、LXGW WenKai（文楷，适合长文） | Noto Serif CJK JP、Noto Sans CJK JP、BIZ UDPMincho、BIZ UDPGothic、Zen Old Mincho、Shippori Mincho | Source Serif 4、Merriweather、Lora、EB Garamond、Crimson Pro、Inter、Source Sans 3、IBM Plex Sans |
| 标题 | Noto Sans CJK SC 的 Bold / Black、Noto Serif CJK SC 的 Bold / Black、Smiley Sans（得意黑） | Zen Kaku Gothic New、Dela Gothic One、M PLUS 1 | Playfair Display、Montserrat、Poppins、Oswald、Bebas Neue（只有大写） |
| 公文 | Zhuque Fangsong（朱雀仿宋，正文）、Noto Serif CJK SC Bold（小标宋） | | |
| 书法与活泼 | Ma Shan Zheng（毛笔楷书）、Long Cang（手写）、ZCOOL XiaoWei、ZCOOL KuaiLe、ZCOOL QingKe HuangYou、AR PL UKai CN（楷体） | Klee One（手书风）、Rounded Mplus 1c、Zen Maru Gothic（圆体） | Quicksand、Nunito、Comic Neue |
| 代码 | Noto Sans Mono CJK SC | | JetBrains Mono、Fira Code、IBM Plex Mono |
| 替代 Office 字体 | | | Liberation Sans / Serif / Mono（Arial / Times New Roman / Courier New）、Carlito（Calibri）、Caladea（Cambria）、Gelasio（Georgia） |

- 思源黑体、思源宋体有 7 档字重（黑体 100～900，宋体 200～900）；英文设计字体大多有 300～900 的真字重，可放心用 `font-weight`。
- 只有一个字重的字体（站酷、马善政、龙藏、Dela Gothic One、Bebas Neue 等）不要再加粗，会被机械加粗变糊。得意黑本身是斜体设计，只有这一种样式。

### 程序里写字体

- **CSS（weasyprint）**：`font-family` 写上表里的字族名，例如 `font-family: 'Noto Serif CJK SC'; font-weight: 900`。
- **LibreOffice、docx、pptx**：直接写字族名；Windows 字体名也可以（见下节）。
- **LaTeX**：见上面 LaTeX 一节。
- **matplotlib**：改 `font.family` 列表（见“数据分析与画图”）。
- **reportlab、fpdf2**：要字体文件路径，用 fontconfig 查：`fc-match -f '%{file}' 'Lora:Bold'`。
  reportlab 只支持 TrueType 轮廓：思源字体（`.ttc`）不能用；中文可用 LXGW WenKai、Zhuque Fangsong、AR PL UKai CN、WenQuanYi Zen Hei，
  日文可用 BIZ UDPGothic、IPAexGothic、Zen Kaku Gothic New 等单文件字体（`TTFont("名字", 路径)` 注册）。fpdf2 能加载思源，但只会取字体集合的第一面（日文字形），中文同样建议用上面那些。
- **Pillow**：思源是字体集合，要带字面序号：`path, idx = subprocess.check_output(["fc-match", "-f", "%{file}|%{index}", "Noto Sans CJK SC"], text=True).split("|")`，
  再 `ImageFont.truetype(path, 48, index=int(idx))`。

## 已知的坑

1. weasyprint 读本地 HTML 文件时，没有 `<meta charset="utf-8">` 就按 windows-1252 解码，中文全成乱码。
2. tesseract 识别只有一行字的小图要加 `--psm 7`，否则版面分析会把它认乱。
3. matplotlib 只在 `font.family` 列出的字体之间回退：写成 `["serif"]` 会缺中文字，要写 `["serif", "Noto Serif CJK SC"]`。
4. reportlab 用不了思源字体；fpdf2 用思源时只会取日文字形。程序画 PDF 时中文选单文件的 TTF 字体。
5. 同一账号同时跑多个 soffice 只有一个成功，要用 `-env:UserInstallation=file:///tmp/lo-<编号>` 分开。
6. XeLaTeX 的 PDF 里思源字体显示为 `NotoSerifCJKjp`，字形是简体，不用处理。
7. plotly 导不出静态图（没有浏览器内核），用 matplotlib。
8. 输出超过 16 KiB 只回传尾部：大量输出写文件。命令超过 600 秒会被终止：长任务拆开。

## 没有的东西

| 没有 | 用什么代替 |
| --- | --- |
| 浏览器内核（Chrome、Playwright、kaleido） | HTML 转 PDF 用 weasyprint；静态图表用 matplotlib |
| Java（tabula、pdftk） | 表格抽取用 pdfplumber 或 PyMuPDF 的 `page.find_tables()`；PDF 处理用 qpdf、pikepdf |
| 完整版 TeX Live | 已装 XeLaTeX / LuaLaTeX 与中日文、常用宏包；缺的宏包无法安装，换用已有宏包 |
| sudo、apt | `pip install`、`npm install` 装到自己的目录 |
